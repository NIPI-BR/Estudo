Comece pelo Modo Demonstração para ver o app lendo as falhas do seu Fiat Mobi (dados simulados). Para ler o carro de verdade, veja qual é o seu adaptador em “Qual adaptador eu tenho?” abaixo — o tipo de conexão (Bluetooth clássico, BLE, Wi‑Fi ou USB) muda o caminho.
❓ Qual adaptador eu tenho? (importante)
• Bluetooth clássico (o mais comum e barato, pareia como “OBDII”, PIN 1234) — não funciona no navegador. Precisa do app Android nativo (próxima fase).
• Bluetooth LE / 4.0 — funciona aqui pelo botão “Bluetooth (BLE)”.
• Wi‑Fi (cria rede “WiFi_OBDII”, IP 192.168.0.10) — precisa do app desktop (próxima fase).
• USB / cabo — funciona aqui pelo botão “USB (Serial)”.
